# Portofoliu Aplicații C#

## Scopul proiectului
Acest repository conține o colecție de aplicații consolă dezvoltate în C# (DreptunghiApp, CatalogNote, ProduseApp și MeniuAplicatie) pentru exersarea structurilor de control, a tablourilor, a validării datelor și a lucrului cu Git/GitHub.

## Tehnologii utilizate
* **Limbaj:** C# (.NET)
* **Mediu de dezvoltare:** Visual Studio
* **Control versiuni:** Git & GitHub

## Structura aplicațiilor
1. **DreptunghiApp** – Calculează aria și perimetrul unui dreptunghi, incluzând validare pentru valori negative sau zero.
2. **CatalogNote** – Gestionează un set de minimum 6 note și calculează media generală.
3. **ProduseApp** – Afișează o listă de produse și calculează prețul total.
4. **MeniuAplicatie** – Un meniu interactiv în consolă cu opțiune de ieșire controlată.
